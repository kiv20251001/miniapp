## 对外文案怎么写

- 用宝妈自己在用的口气，先写场景，再写能做什么。一篇不要铺开所有功能。
- 对外说全名「Uday家庭课表计划」。简称搜索不一定能找到。
- 课程统计没有删除，在今日页的统计卡片里。文案不要写成统计没了。
- 不写「最全、免费、培训、在线教学」。太阳系没有配音，不要写成能听讲解。
- 配图用自己手机截的页面。不要用网页图、别人的截图。
- 新的一篇加在「发布记录」最上面，写上日期和平台。单工具的使用介绍也加在这里，先写什么时候用，再写打开后的两三步。

### 2026-11-19 · 小红书 · 工具箱上线

标题：

```text
底栏那个统计，我换成给孩子用的了
```

正文：

```text
以前打开这个小程序，就是看今天上什么课、兴趣班在哪。
底下那一栏是统计。账单不是不能看，是孩子坐下来写作业的时候，它帮不上忙。

所以这一栏现在叫工具箱。
课表还在原来的地方。想看这周花了多少，今日页上的统计卡片还能点进去，没有拿掉。

现在里面这几样，都是在家就能用的：

字帖。要写的字输进去，或者一段英文单词。田字格、米字格、四线格都能出，也能按年级带一批生字。排好就是 A4，存成图片或 PDF 去打印。

口算。凑十法、破十法，还有加减混合。一年级最常练的那几页，自己出，不用再到处找卷子。

认识时钟。自己拨时针分针，天色会跟着变。会认了可以做小测验，也能把题目打出来。

认识分数。披萨切开，拿出来的是分子，一共几份是分母。同样能做题、能打印。

太阳系。行星谁大谁小、怎么转，月相和四季可以转着看。点一颗星球有讲解。没有配音，适合挨着一起看。

微信里搜「Uday家庭课表计划」。
每个工具后面还会单独写怎么用。
```

话题：

```text
#一年级 #口算 #字帖 #认识时钟 #宝妈日常
```

封面字用标题那句。图用工具箱这一屏，五个工具都露出来。
